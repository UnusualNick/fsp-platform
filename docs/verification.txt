Проверки FSP

Полный набор:
docker compose run --rm --no-deps platform python -m unittest discover -s tests -v

39 тестов проверяют права ролей, регистрацию, согласия, тестирование, блокировку повторной отправки, поиск, приглашения, вакансии, отклики и задания недели.

Сквозной сценарий:
docker compose exec -T platform python scripts/smoke.py

Сценарий создаёт записи в демонстрационном экземпляре и проверяет подбор, приглашение, открытие контактов после согласия, создание и редактирование вакансии, отклик и решение по нему, привязку участника и PDF.

Модельная проверка:
python validate.py

Результаты: data/validation-results.json. Методика и границы выводов: docs/organizer-clarifications.md, раздел «Валидация теста».

Проверка чтения HTTP:
python scripts/load_readonly.py --base http://127.0.0.1:8080

Результаты: data/http-load.json. Скрипт выполняет 100 запросов с параллелизмом 8. Нагрузка на запись в эту проверку не входит.
