# Материалы предыдущей версии

Эти PDF, презентация и видео показывают предыдущую версию интерфейса. Они сохранены для доработки, не являются проверенным финальным комплектом сдачи. Актуальные тесты версии 2026.10.2 содержат 12 заданий; текущие требования, возможности и ограничения описаны в основном README и docs/. Поля состава команды в презентации требуют заполнения.
